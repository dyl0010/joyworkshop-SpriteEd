# 5. 更激进的功能策略

既然是你个人使用，我建议不要完全按“商业软件 MVP”路线走。

商业软件路线通常是：

```text
稳定
通用
新手友好
功能保守
```

但个人工具可以更激进：

```text
快捷键优先
命令面板优先
实时预览优先
允许高级参数暴露
允许 UI 粗糙但功能强
允许非标准工作流
```

所以我建议你的开发优先级改成：

```text
画布体验 > 提取能力 > 动画预览 > 打包导出 > UI 美观
```

而不是传统的：

```text
导入 > 打包 > 导出 > 设置面板
```

# 7. 数据模型建议

为了支持你的 UI，数据模型要围绕“画布对象”设计。

```cpp
struct SpriteRect {
    std::string id;
    std::string name;

    int x;
    int y;
    int w;
    int h;

    int sourceW;
    int sourceH;
    int offsetX;
    int offsetY;

    float pivotX = 0.5f;
    float pivotY = 0.5f;

    bool selected = false;
    bool locked = false;

    std::vector<std::string> tags;
};
```

动画：

```cpp
struct AnimationClip {
    std::string name;
    std::vector<std::string> frameSpriteIds;
    float fps = 12.0f;
    bool loop = true;
    bool pingPong = false;
};
```

项目：

```cpp
struct Project {
    std::string sourceImagePath;
    std::vector<SpriteRect> sprites;
    std::vector<AnimationClip> animations;
};
```

建议第一版项目文件就是 JSON：

```text
.sprited.json
```

# 8. 画布架构建议

画布不要只是一个 ImGui::Image。

建议封装成：

```cpp
class CanvasView {
public:
    void draw();
    void setTexture(TextureHandle texture);
    void fitToWindow();
    void zoomAt(ImVec2 screenPoint, float zoomDelta);
    void pan(ImVec2 delta);

    ImVec2 screenToCanvas(ImVec2 screen) const;
    ImVec2 canvasToScreen(ImVec2 canvas) const;

private:
    ImVec2 pan;
    float zoom;
};
```

核心是坐标转换：

```text
屏幕坐标 <-> 图像坐标
```

后续所有框选、拖拽、像素检测、sprite rect 都依赖这个。

# 12. 最重要的建议

如果你希望工具真的好用，我建议你不要先做大量表单设置。

你应该先做好这个闭环：

```text
打开一张精灵表
在中心画布中缩放/移动

按 A 加入动画
按 Space 播放
按 Ctrl+Shift+G 导出 GIF
```

这个闭环一旦打通，工具马上有价值。

之后再加：

```text
自动提取
打包
导出 JSON

```

# 13. 最终推荐路线

我建议你的第一阶段目标改成：

```text
中心画布驱动的 sprite sheet editor
```

而不是：

```text
普通 texture packer
```

第一阶段功能：

```text
1. ImGui 主窗口
2. 中心 Canvas 渲染图片
3. 缩放、平移、棋盘格、坐标显示
4. 手动框选 sprite
5. Sprite Inspector 浮窗
6. Grid Extractor 浮窗
7. Animation 浮窗
8. 中心画布播放动画
9. 保存/加载 .sprited.json
10. 导出 GIF 或 JSON
```

第二阶段再做：

```text
多图打包
自动裁剪
MaxRects
padding/extrude
atlas.png 导出
```

这会更符合你的个人使用目标，也更激进、更快获得实际价值。
